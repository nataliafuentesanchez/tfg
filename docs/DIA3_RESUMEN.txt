⚠️  PROBLEMAS ENCONTRADOS EN INTEGRACIÓN SUPERVISADA:

Intento 1: Reemplazo directo
┌───────────────────────────────────────────────────────────────┐
│ Lógica: Si modelo RF tiene confianza alta (proba[max] > 0.60),│
│         usa probabilidad RF como risk_score                    │
│ Resultado: F1 degradó de 0.48 a 0.31 ❌                       │
│ Causa: Data leakage (risk_score incluido en features de RF)   │
└───────────────────────────────────────────────────────────────┘

Problema específico:
   • Lesión sintética con heurístico score = 0.56 (→ ENFERMO)
   • Modelo RF predice: SANO con proba[0] = 0.85
   • Test falla: expected ENFERMO, got SANO

Diagnóstico:
   • El heurístico score fue incluido como feature en entrenamiento
   • RF aprendió a invertir/ignorar características reales cuando
     risk_score baja presenta señales contradictorias
   • Resultado: overfitting a datos de entrenamiento, mala
     generalización a casos nuevos

Impacto en benchmark:
   ┌────────────────┬──────────┬──────────┬────────┐
   │ Métrica        │ Heurístico│ RF integr│ Cambio │
   ├────────────────┼──────────┼──────────┼────────┤
   │ Precision      │ 0.4066   │ 0.5326   │ +31%   │
   │ Recall         │ 0.5915   │ 0.2145   │ -64% ❌│
   │ F1-Score       │ 0.4819   │ 0.3058   │ -37% ❌│
   │ Accuracy       │ 0.5796   │ 0.6782   │ +17%   │
   └────────────────┴──────────┴──────────┴────────┘

Conclusión: No mejoró, de hecho empeoró recall drásticamente.
