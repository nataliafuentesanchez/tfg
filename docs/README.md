# Documentacion del Proyecto

Este directorio contiene la documentacion funcional y tecnica de AnalisisImagenes.

## Archivos principales

- `SPECIFICATIONS.md`: requisitos funcionales y criterios de evaluacion.
- `ARCHITECTURE.md`: decisiones de arquitectura y stack tecnico.
- `DESIGN.md`: lineamientos visuales de la interfaz web.

## Archivos de soporte metodologico

Los siguientes documentos se mantienen como referencia del flujo SDD de trabajo:
- `MASTER_PROMPT.md`
- `ADOPTION_PROMPT.md`
- `UPGRADE_PROMPT.md`
- `AGENTIC_ENGINEERING.md`

Nota: estos archivos de soporte metodologico no describen funcionalidad del producto, sino el marco de desarrollo.
